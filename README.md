# Mythic Tamers

A Roblox **magical creature simulator** with a competitive layer. Players click mana crystals to earn
Essence, hatch magical creatures from eggs, unlock new realms, rebirth for permanent multipliers, and
compete in server-wide **Mana Surges** and a weekly cross-server **House War**.

- **[docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)**: every system, the economy numbers and the monetization plan
- **[docs/MARKET_RESEARCH.md](docs/MARKET_RESEARCH.md)**: what makes the top simulators different, and which ideas we borrowed
- **[docs/ICONS.md](docs/ICONS.md)**: generated icons for every game pass and product
- **[docs/SOUNDS.md](docs/SOUNDS.md)**: sound effects, music, and how to swap in your own
- **[docs/CREATURE_MESHES.md](docs/CREATURE_MESHES.md)**: 3D models (GLB) of all 25 creatures and how to import them
- **[docs/WORLD_MESHES.md](docs/WORLD_MESHES.md)**: 3D models for eggs, crystals, Mana Chests, the merchant stall and trees, and how to import them

## Live sync with Roblox Studio (recommended)

Keep **one** place open in Studio and every change pushed to this repo appears in it automatically.
No more opening new `.rbxl` files.

**One-time setup**
1. Install [Git](https://git-scm.com/downloads) and [Rokit](https://github.com/rojo-rbx/rokit), then in this folder run:
   ```
   git clone https://github.com/jacklukasmith-cloud/roblox.git
   cd roblox
   rokit install
   ```
2. Install the **Rojo** plugin in Studio (Creator Store → search "Rojo", or run `rojo plugin install`).
3. Open your place in Studio (or a blank Baseplate), then **File → Publish to Roblox** so saving and imports work.

**Every session**
1. Start the sync script and leave it running:
   - Windows: `powershell -ExecutionPolicy Bypass -File scripts\sync.ps1`
   - Mac/Linux: `./scripts/sync.sh`
2. In Studio, open the **Rojo** plugin and click **Connect**.
3. That's it. The script checks for new changes every 15 seconds; Rojo pushes them into Studio within a second or two.
   Press **Play** to test. Save/publish the place as usual (Ctrl+S / Alt+P).

What Rojo controls: the scripts (`ServerScriptService.Server`, `StarterPlayerScripts.Client`, `ReplicatedStorage.Shared`) and
the Lighting settings. Anything else you build in Studio is left alone, including the creature meshes you import into
`ReplicatedStorage.CreatureMeshes`. Edit the scripts here, not in Studio: Rojo overwrites Studio-side script edits.

## Quick start (one-off build)

If you just want a file: `rojo build -o MythicTamers.rbxl`, open it in Studio and press **Play**.
The whole map (hub, 4 zones, crystals, eggs, gates, boards) is generated by code when the game runs.

> To test game passes in Studio without buying them, set `Config.StudioOwnsAllPasses = true` in
> `src/shared/Config.luau`. Turn it back off before publishing.

## Before you publish

1. **Publish the place**, then in *Game Settings → Security* turn on **Enable Studio Access to API Services**
   (needed for saving, leaderboards and the House War).
2. On the [Creator Hub](https://create.roblox.com/) create the **7 game passes** and **5 developer
   products** listed in `src/shared/Config.luau`. Upload the icons from [docs/ICONS.md](docs/ICONS.md).
3. Paste each ID into `Config.GamePasses` / `Config.DevProducts` (`Id = 0` means "not set up", and the shop shows it
   as unavailable). Optionally set `Icon = "rbxassetid://..."` so the shop shows the artwork.
   The **Nebula Kitsune** is a Robux-only creature (the `NebulaKitsune` developer product, featured at
   the top of the Shop). Players can buy it more than once. Test it in Studio with `!give NebulaKitsune`.
4. Add any co-admins' UserIds to `Config.AdminUserIds` (the place owner is always an admin).

## Admin live events (type in chat)

Broadcast to **every server** at once, like Grow a Garden's "admin abuse" events:

| Command | Effect |
|---|---|
| `!surge` | Start a Mana Surge right now |
| `!weather ManaStorm 10` | Force a weather for N minutes (`Clear`, `Starfall`, `Aurora`, `Eclipse`, `ManaStorm`) |
| `!announce Double luck weekend!` | Message every player |

Testing commands (only affect you; everyone is an admin in Studio):

| Command | Effect |
|---|---|
| `!essence 1000000` | Give yourself Essence |
| `!give EmberFox Shiny` | Add a creature (optional `Shiny` / `Rainbow`) |
| `!giveall` | One of every creature |
| `!hatchtest Phoenix Rainbow` | Play the hatch animation for up to 3 creatures (nothing is added) |
| `!bigpull Phoenix Rainbow` | Preview the big-pull banner and fireworks (Legendary or better, or any Rainbow) |
| `!treasure` | Hide a Lost Treasure now (add a realm number, e.g. `!treasure 2`) |
| `!boss` | Spawn a boss raid now (add a realm number, e.g. `!boss 2`) |
| `!nopasses` | Play as if you owned no game passes, to test the real difficulty (type it again to undo). In Studio you own every pass by default (`Config.StudioOwnsAllPasses`) |
| `!item LuckPotion 5` | Put items in your Bag (`!item all` gives 5 of each) |
| `!reset confirm` | Wipe all your progress back to a brand-new save (Robux purchases and game passes are kept) |
| `!seasonend` | End the season now on this server and hand out the rewards (for testing) |

## The hub

The hub is about twice as big as before and split into districts:
- **Centre:** the spawn, the plaza with the Mana Surge obelisk and the Champion Egg, with a clear walkway back to the portals.
- **Leaderboards:** the Trophy board (with the top-3 statues) and the Season board stand at the back of the west wing,
  and the House War board at the back of the east wing. All three face the middle.
- **West wing:** the Wandering Merchant and the Blacksmith. Each has a glowing **shop circle**: walk in and its window opens, walk out and it closes.
- **House Quarter** (east wing): the three House statues.
- **Portal Plaza** (behind the spawn): a fountain and two *coming soon* portals, for the Gloomwood and
  your Sanctuary.

The realms start in the same place as before.

## Missions

A chain of 20 missions guides players from their first crystal to discovering all 25 species
(`src/shared/Missions.luau`). Each one pays Essence (the last ones pay Trophies and the "Master Tamer"
title). The **mission card** sits under the left menu and shows the mission, progress and reward.
For the first 7 missions a glowing line and arrow point to where the mission happens. After that, tap
the card to turn the arrow on or off; this also shows a tip. To add, remove or reorder missions, edit
`Missions.List`. Players already past a mission keep their place, and anything they've already done
(like realms unlocked) completes straight away.

## The Bag (items)

Potions and other items go into your **🎒 Bag** (menu key 2), so you choose when to use them.
Tap an item to see what it does, then press **Use** (or **Open** for gifts). Items are listed in
`src/shared/Items.luau`:

| Item | What it does |
|---|---|
| 🍀 Luck / ⚗️ Essence / ✨ Shiny / 💨 Speed / 💪 Power / 📈 XP Potion | A 10-minute boost |
| 🌈 Rainbow Brew | Luck, Essence, Shiny and Power together for 15 minutes |
| 🍪 Pet Treat / 🍯 Golden Treat | Instant XP for every equipped creature |
| 💰 Essence Sack | Instant Essence |
| 🥚 Mystic Egg | Hatches a guaranteed Rare or better |
| 🎁 Mystery Gift | Opens into a random item |
| 🗺️ Treasure Map | Hides a Lost Treasure in one of your realms |
| 📯 Boss Horn | Calls a boss to the server right now |

**Where items come from:**
- crystals (a small chance, more for big ones);
- every Mana Chest and Lost Treasure;
- bosses (a Mystery Gift plus a rare item);
- the Wandering Merchant;
- daily rewards, missions and hatching milestones;
- the Robux Luck Potion product (2 potions).

Drop chances are in `Config.ItemDrops`. Test with `!item LuckPotion 5` or `!item all`.

## Leaderboards

The **🏆 Top** button (top-right) opens the leaderboards window. It has 6 categories, listed in `src/shared/Boards.luau`:
- all-time: **Trophies**, **Essence Earned**, **Rebirths** and **Species Found**;
- weekly, resetting every Monday (so new players can get on them): **Crystals This Week** and **Eggs Hatched This Week**.

Each board has a **🌍 Global** top 50 with avatar pictures and a **👥 Friends** tab (you and your Roblox friends), and it
always shows **your own rank**. If you're not in the top 50, it shows how much more you need to get on.

In the hub, the Trophy board (west wing) cycles through every category every 12 seconds. Statues of the **top 3 trophy holders**
(their real avatars) stand on top of it. Scores are saved every 90 seconds, and only when they've changed.

## Friend Boost

You get **+5% Essence for each Roblox friend in your server**, counting up to 3 friends (+15%). Change this in
`Config.FriendBoost`. A 👥 chip above the Essence bar shows it, and both players get a message when a friend joins.
**Invite friends** buttons in the Trade menu and Settings open Roblox's invite screen.

## Codes

Players type codes in **Settings** (🎟️ box, then Redeem) for free rewards. The list is in
`src/server/Services/Codes.luau`, on the server only, so codes can't be read out of the game. Each player can use a
code once, case doesn't matter, and a code can have an expiry date. To add one, add a line like
`SUMMER = { Rewards = { Essence = 100, Items = { LuckPotion = 2 } } },`. Starting codes: **RELEASE**,
**MYTHIC**, **TAMER**, **THANKYOU**.

## Trading

Use the **🤝 Trade** menu to trade creatures and Bag items with anyone in the same server. This is how it works,
in the style of Adopt Me and Pet Simulator 99:
1. Send a request. The other player gets a pop-up to accept (it lasts 30 s).
2. Both sides add up to 12 creatures and 12 kinds of items. Tap your own tile to take it back.
3. Both press **Ready**. A **5-second lock** counts down, and any change or Cancel stops it.
4. The server checks everything is still owned and that storage has room. It then swaps both sides at
   once, saves both players straight away and adds it to both trade logs (`TradeLog` in the save, the
   last 20 trades). It also prints a line in the server log.

Creatures keep their level and arrive unequipped. Accounts whose Roblox policy doesn't allow trading paid items
can't trade.

## Daily rewards & quests

The **🎁 Daily** button (top-right, key **7**) opens by itself when a reward is waiting; a red bubble on the
tile counts rewards ready to claim. Days roll over at midnight UTC.

- **7-day login streak:** Essence → Luck Potion → Essence → Essence Potion → 5 Trophies → Shiny
  Elixir → **Mystic Egg + big Essence**, then the cycle repeats. Miss a day and it starts over.
- **3 daily quests** (same for everyone that day), e.g. "Break 50 crystals", "Hatch 10 eggs",
  "Open 2 Mana Chests". Each pays Essence; finishing all three unlocks a bonus Luck Potion.

![Daily](docs/images/ui-daily.png)

Rewards and the quest pool live in `src/shared/Daily.luau`; Essence rewards scale with your best zone.
