# Creature 3D models

All 26 creatures have a textured 3D model (GLB) made with Higgsfield:
first a concept image (GPT Image), then image to 3D with **SAM 3D (Meta)**.

The game already supports them. Any creature whose model is in **ReplicatedStorage → CreatureMeshes**
uses the real mesh automatically (followers, inventory, bestiary, egg odds boards and statues).
Creatures without one keep the built-in part model, so you can import them one at a time.

## Import into Roblox (about 2 minutes for all 26)

With the live sync running (see README):

1. **Download them all, already named.** In PowerShell, in the `roblox` folder:
   ```
   git pull
   powershell -ExecutionPolicy Bypass -File scripts\download-creatures.ps1
   ```
   (Mac: `./scripts/download-creatures.sh`.) This creates a `creature-models` folder with `EmberFox.glb`, `Phoenix.glb`, and so on.
2. **Import them.** In Studio: **Home → Import 3D**, go to `Documents\roblox\creature-models`, select **all** the `.glb` files
   (Ctrl+A) and import. If your Studio only lets you pick one file at a time, repeat for each.
   Leave the default settings; each creature appears in the Workspace as a model named after its file.
3. That's it. You can leave the models where the importer put them (in Workspace): when the game starts it
   automatically moves any model named after a creature into `ReplicatedStorage.CreatureMeshes`.
   (Optional, to keep the Workspace tidy: drag them into that folder yourself, or paste
   `scripts/organize-creatures.lua` into **View → Command Bar**.)
4. **Save the place** (Ctrl+S, or File → Publish to Roblox). Press Play: your creatures now use the 3D models.

Rojo leaves the `CreatureMeshes` folder's contents alone, so the meshes stay put while syncing.
If you ever rebuild the place from scratch with `rojo build`, save each model as `assets/creatures/<Name>.rbxm`
(right-click → Save to File) so it's included automatically.

### Fine-tuning (optional attributes on the model)

| Attribute | Type | What it does |
|---|---|---|
| `Yaw` | number (degrees) | Rotate the creature if it doesn't face forward (try `180` or `90`) |
| `Scale` | number | Make this creature bigger/smaller than the default for its rarity |
| `Lift` | number (studs) | Nudge it up/down |

The game resizes each mesh to its rarity's size and adds gentle hover/sway animation.
Shiny creatures get a reflective sheen and sparkles; Rainbow creatures get a colour-cycling glow.

## Notes on quality

- These used the cheap **SAM 3D** model (1 credit each). If any come out lumpy, regenerate that creature with
  **Tripo H3.1** (about 9 credits) or **Meshy** (about 30 credits textured) from the same concept image.
- Single-image 3D has to guess the back of the creature, so check each model from behind.
- Mesh creatures don't flap or wag like the built-in models; they sway as one piece.
  For real animation, rig them in Blender or use Higgsfield's rigging tool.
